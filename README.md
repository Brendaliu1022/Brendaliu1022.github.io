# Brendaliu1022.github.io

Personal website of Yutong Liu, served by GitHub Pages at https://brendaliu1022.github.io

## How to update

- **Add a project image:** put the image in `assets/projects/` (JPG/PNG, about 1600 px wide, under 1 MB), then in `index.html` find that project's `<!-- <figure>...</figure> -->` line, change the file name if needed, and delete `<!--` and `-->`.
- **Add your CV:** upload a web version (no phone number or home address) as `assets/Yutong_Liu_CV.pdf`, then uncomment the CV link near the top of `index.html`.
- **Add a research figure:** only after Prof. Shimane approves. Put it in `assets/research/` and uncomment the RESULT FIGURE block.
- **Change your photo:** replace `assets/img/yutong.jpg` with a square image using the same file name.

Edit files directly on github.com (pencil icon) and click "Commit changes". The site updates in about a minute.
