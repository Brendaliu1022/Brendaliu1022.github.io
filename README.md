# Brendaliu1022.github.io

Personal website of Yutong Liu, served by GitHub Pages at https://brendaliu1022.github.io

## Files
- `index.html` – the page
- `style.css` – all styling (upload it together with index.html, or the page will look broken)
- `assets/img/yutong.jpg` – portrait (keep this exact name)
- `assets/work/` – internship photos
- `assets/projects/` – SolidWorks / course project images

## Add a project image
Put the image in `assets/projects/` (JPG/PNG, about 1600 px wide, under 1 MB). In `index.html`, find that project's `<!-- <figure>...</figure> -->` line, check the file name, and delete `<!--` and `-->`.

## Add your CV
Upload a web version (no phone number or home address) as `assets/Yutong_Liu_CV.pdf`, then uncomment the CV link near the top of `index.html`.
